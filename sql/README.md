# SQL Queries

Store each project query in this folder as a numbered SQL file, using a descriptive step name (for example, `01_data_profile.sql`). Keep the numbers in execution order.

For each query, document its purpose, source tables, important assumptions, and how to interpret or validate the result in comments or in the related project notes. Add a new numbered file for each query as the analysis develops.

The dataset and query plan have not been documented here yet; fill in those details when the queries are defined.
